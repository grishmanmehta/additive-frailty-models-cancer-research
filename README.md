# Additive Frailty Models for Recurrent Events in Cancer Research
Statistical modeling project investigating cancer recurrence using Additive Frailty Models, Survival Analysis, and Gamma Frailty Distributions to capture patient-level heterogeneity and recurrent event patterns.
A survival analysis project focused on modeling cancer recurrence through additive frailty models, recurrent event analysis, and patient-specific risk estimation.
Objectives
Investigate recurrence patterns in cancer patients.
Evaluate limitations of the Cox Proportional Hazards Model.
Identify appropriate frailty distributions.
Estimate patient-level frailty.
Compare parametric and nonparametric survival estimators.
Methodology
Cox Proportional Hazards Model
Schoenfeld Residual Tests
Additive Frailty Models
Gamma Frailty Distribution
Hazard Ratio Analysis
Wang-Chang Nonparametric Estimator
Tools Used
R
Survival Analysis
Statistical Modeling
Biostatistics
